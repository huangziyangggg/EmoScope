# 心镜首页「安静陪伴」设计

## 目标

在不改变快速记录、语音倾诉、面容分析既有行为的前提下，收敛首页视觉层级，让小屏首屏保持轻盈、清晰且无内容遮挡。

## 布局

1. 保留日期胶囊、动态问候、语音播报开关和三个核心入口。
2. 标题区缩短为日期、最多两行问候和一句辅助说明；标题文字为语音按钮预留右侧空间。
3. 三个入口卡片保持同一高度、左图标/中间文本/右箭头三段式结构，卡片间使用一致留白。
4. 只使用低饱和橙、蓝、绿区分入口；减少大面积背景装饰的存在感。
5. 首页不增加演示数据，AI 回应卡片仅在实际获得结果时显示。

## 边界与验证

- 不修改数据库字段、记录含义、导航行为、权限行为或 AI 请求逻辑。
- 适配 1080×2400 小屏模拟器，底部导航上方的三入口不重叠、不裁切。
- 使用 `assembleDebug`、`testDebugUnitTest`、`:app:lintDebug`、`git diff --check` 和模拟器截图验证。
- 本轮不创建 Git 提交，遵从工作区协作约定。
